# Skill: Educational Resource Production

## Purpose

Turn teaching experience, classroom routines, and project guidance methods into reusable, editable, and shareable educational resources.

## Problems This Skill Solves

- Classroom experience remains informal and is difficult to reuse.
- Student materials use inconsistent formats and process records become messy.
- Teacher co-planning lacks shared templates and creates extra coordination work.
- Many resources exist, but they are not categorized or explained clearly.

## Workflow

1. Identify the user of the resource: students, teachers, or a co-planning team.
2. Define the use case and expected output.
3. Organize instructions, steps, examples, and blank templates in a stable structure.
4. Add suggested grade level, duration, preparation materials, and cautions.
5. Test the resource once in a realistic teaching scenario and revise it.
6. Maintain naming, versioning, and archive conventions.

## Typical Outputs

- Student worksheet
- Project journal template
- Teacher guide
- Classroom flow card
- Presentation material template
- Topic resource index

## Public Boundary

This skill shares general resource production methods. It does not include internal paid materials, real identity details, private student information, or income-related content.
