# Education Skills Topics

This folder organizes education-focused skills as reusable public resources. The materials are written as general educational practice notes and avoid private identity details, student information, school-specific information, paid-service claims, and income-related content.

## Topics

| Topic | Focus | Main Skill |
| --- | --- | --- |
| Curriculum Design | Course goals, unit design, learning task chains | [Course Development](curriculum-design/course-development-skill.md) |
| Teaching Methodology | PBL, inquiry learning, classroom facilitation | [Project-Based Learning Design](teaching-methodology/pbl-design-skill.md) |
| Assessment & Feedback | Rubrics, formative assessment, revision loops | [Rubric & Feedback Design](assessment-feedback/rubric-feedback-skill.md) |
| AI & EdTech | AI-assisted teaching, online learning, tool boundaries | [AI-Assisted Teaching Design](ai-edtech/ai-assisted-teaching-skill.md) |
| Programming & STEM | Python, web, algorithms, computational thinking | [Programming & STEM Teaching](programming-stem/programming-stem-skill.md) |
| Resource Production | Worksheets, templates, activity guides, documentation | [Educational Resource Production](resource-production/resource-production-skill.md) |
| Student Guidance | Topic selection, planning, evidence chains, presentations | [Student Project Guidance](student-guidance/student-project-guidance-skill.md) |

## Public Boundary

These skills are shared as education-domain summaries. They are not presented as commercial services, paid consulting records, admissions promises, school endorsements, or income-related materials.
