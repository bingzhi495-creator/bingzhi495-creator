# Skill: Rubric & Feedback Design

## Purpose

Turn assessment criteria into feedback tools that students can understand, teachers can apply consistently, and projects can use for revision.

## Problems This Skill Solves

- Evaluation criteria are too vague for students to act on.
- Teacher feedback is rich, but students do not know how to revise.
- Project process evidence is missing, so only the final product is assessed.
- Scores separate performance levels but do not support growth.

## Workflow

1. Define what is being assessed: process, product, presentation, reflection, or a combination.
2. Choose 3 to 5 core dimensions that match the learning goals.
3. Describe observable behaviors for each dimension instead of abstract adjectives.
4. Write performance levels that show students how to move to the next level.
5. Pair the rubric with feedback sentence stems and revision suggestions.
6. Use the rubric across draft, midpoint, and final review cycles.

## Typical Outputs

- Rubric table
- Formative assessment checklist
- Student self-assessment form
- Peer review form
- Teacher feedback template
- Revision plan

## Public Boundary

This skill documents assessment design methods. It does not publish real student grades, identifiable learning records, private feedback logs, or commercial evaluation services.
