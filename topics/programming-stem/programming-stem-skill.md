# Skill: Programming & STEM Teaching

## Purpose

Organize programming, data, algorithms, and scientific inquiry into learning projects that students can understand, build, explain, and improve.

## Problems This Skill Solves

- Students copy code but cannot explain the logic.
- Programming tasks feel disconnected from real problems.
- STEM projects produce artifacts but lack data and explanation.
- Learning paths jump too quickly and students lose confidence.

## Workflow

1. Start from a real-world question, classroom phenomenon, or learner interest.
2. Break the task into input, processing, output, and explanation.
3. Build a minimum working version before adding complexity.
4. Guide students to document errors, debugging steps, and revision reasons.
5. Turn code results into charts, reports, demonstrations, or presentations.
6. Assess logic, implementation, explanation, and reflection together.

## Typical Outputs

- Programming learning path
- Project task sheet
- Code explanation template
- Debugging journal
- STEM project report frame
- Presentation outline

## Public Boundary

This skill does not upload real student repositories, personal accounts, grades, unauthorized work, or competition-sensitive materials.
