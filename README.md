## 我关注的问题

- 如何让学生从“想做一个大项目”走到“能验证一个小问题”
- 如何把 AI 工具放进真实学习流程，而不是只做表面展示
- 如何让项目化学习更重视证据、表达和迭代
- 如何设计学生能听懂、能执行、能复盘的评价标准
- 如何把教师经验整理成可复制的课堂材料和辅导流程

## Coaching Principles

- 先保护隐私，再公开成果。
- 学生必须能解释自己的项目。
- 小问题、真证据、清楚表达，比空泛的大概念更重要。
- AI 可以参与思考，但不能替代数据、实验和学生理解。
- Rubric 的价值不是打分，而是帮助下一轮修改。
- 公开内容保持教育性、非商业性、匿名化和边界清晰。
